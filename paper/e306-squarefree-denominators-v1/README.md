# Paper A: squarefree denominators

This directory contains the characterization paper authorized in issue #8. It is reconstructed selectively from the historical manuscript sequence while taking `4736533cddf11cf7d57c6e567081696ff7bf6552` as the sole mathematical authority.

The article contains the characterization, finite avoidance, the direct fixed-target construction, exact realization, prime dilution, and qualitative refinement consequences. Quantitative local-limit and multiplicity material is deliberately excluded.
