\section{Finite-set bridge to the public tuple}\label{sec:tuple}

The construction produces a nonempty finite set $S$: it cannot be empty because
its reciprocal sum is the positive rational $q$.  Write $|S|=m+1$ and enumerate
it increasingly by
\[
 g:\operatorname{Fin}(m+1)\hookrightarrow\N.
\]
Define $n:\operatorname{Fin}(m+2)\to\N$ by
\[
 n(0)=1,
 \qquad n(j+1)=g(j).
\]
Every squarefree semiprime exceeds $1$, so the anchor is strictly below the
first genuine denominator, and $n$ is strictly increasing.  For every
noninitial index, Lemma~\ref{lem:semiprime-equivalence} gives
$\omega(n_i)=\Omega(n_i)=2$, while
\[
 q=\sum_{i=1}^{m+1}\frac1{n_i}.
\]
The dummy anchor $1$ is excluded from the sum.  This is a bridge from a finite
set to a finite strictly increasing tuple; no infinite sequence is asserted.
