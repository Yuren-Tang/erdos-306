# Erdős 307: moving genus-character obstruction without factoring the port integer

**Programme:** `E306-RL-ADJ-09`  
**Status:** `UNCONDITIONAL NO-GO THEOREM / FACTORIZATION-FREE FILTER`  
**Date:** 2026-07-23

## 1. Purpose

The seeded divisor port has

```text
K=A^2+L B^2,
gcd(A,B)=gcd(A,L)=1,
t=-A mod L,
```

where, in the E307 notation,

```text
A=yD(xp),
B=xp,
L=L_p.
```

A target divisor is a divisor `d|K` with `d=t mod L`.  The exact support-subgroup test usually
requires factoring `K`.  This note extracts a quadratic character obstruction directly from
the primitive norm representation, before factorization.

## 2. Squarefree part and the moving quadratic character

Write

```text
L=L_0 u^2,                                      (2.1)
```

where `L_0` is squarefree.  Then

```text
Q(sqrt(-L))=Q(sqrt(-L_0)).                      (2.2)
```

Assume

```text
L_0 congruent 3 mod 4.                          (2.3)
```

The fundamental discriminant of the field is

```text
D=-L_0,                                         (2.4)
```

and the associated quadratic Dirichlet character

```text
chi_D(n)=(D/n)                                  (2.5)
```

has conductor `L_0`, which divides `L`.  It therefore lifts naturally to a quadratic character
on `(Z/LZ)^x`.

## 3. Odd split factors lie in the kernel

### Theorem 3.1

Every odd prime `lambda|K` satisfies

```text
chi_D(lambda)=+1.                               (3.1)
```

#### Proof

The primitive norm theorem gives

```text
A^2 congruent -L B^2 mod lambda,
```

with `B` invertible modulo `lambda`.  Hence `-L` is a square modulo `lambda`.  Since
`L=L_0u^2`, `-L_0` is also a square modulo `lambda`, so

```text
(-L_0/lambda)=+1.
```

Also `lambda` does not divide `L_0`, because `gcd(K,L)=1`. `square`

Thus every odd prime factor of `K` belongs to the kernel of the same moving quadratic character.

## 4. Factorization-free target obstruction

The only possible exceptional rational prime is `2`.  Assume either

```text
K is odd,                                       (4.1)
```

or

```text
chi_D(2)=+1.                                    (4.2)
```

Then every prime factor of `K`, including `2` when present, has character value `+1`.
Consequently every positive divisor `d|K` satisfies

```text
chi_D(d)=+1.                                    (4.3)
```

### Theorem 4.1 — moving genus obstruction

Under `(2.3)` and either `(4.1)` or `(4.2)`, if

```text
chi_D(t)=-1,                                    (4.4)
```

then

```text
N_t(K;L)=0.                                     (4.5)
```

In E307 variables, the test is

```text
chi_(-L_0)(-yD(xp))=-1.                         (4.6)
```

#### Proof

Any integer congruent to `t mod L` has the same character value as `t`, because the character
has conductor dividing `L`.  But every divisor of `K` has value `+1` by `(4.3)`. `square`

No factorization of `K` is required.

## 5. The two-adic caveat is real

If

```text
K is even,
chi_D(2)=-1,
```

then the odd prime factors still lie in the kernel, but divisors containing an odd power of `2`
have character value `-1`.  The simple obstruction `(4.4)` is no longer valid without tracking
the allowed two-adic valuations of the target divisor.

This is why the theorem explicitly assumes `(4.1)` or `(4.2)`.  One must not silently claim
that every prime factor, including `2`, splits from the odd-prime Legendre-symbol argument.

A refined two-adic port character may be possible by combining:

```text
d=Lq-A
```

with the residue of the output prime `q` modulo `4` or `8`; that refinement is not proved here.

## 6. Relation to the abstract quadratic support certificate

The divisor-residue support theorem says that, whenever the target is outside the subgroup
generated by prime-factor residues, some quadratic character separates it from that subgroup.
The present theorem identifies one such character *a priori*:

```text
moving field splitting character chi_(-L_0).
```

It is therefore a genus-level source of the abstract subgroup obstruction.

The distinction is:

```text
ABSTRACT SUPPORT TEST:
  factor K, generate the residue subgroup, find a separating character;

MOVING GENUS TEST:
  use the primitive norm to write down a separating candidate before factoring K.
```

The genus test is not complete; factor residues may satisfy additional independent quadratic
or higher-order relations.

## 7. Computational diagnostic

In the small seed experiment based on the first six prefix primes and first twelve seed primes,
there were `615` admissible seeds with `L_0 congruent 3 mod 4`.

Restricting to the safe cases `(4.1)` or `(4.2)` left `575` seeds.  Among them:

```text
chi_D(t)=-1, no target divisor : 217,
chi_D(t)=+1, no target divisor : 356,
chi_D(t)=+1, target divisors   :   2.
```

No positive case violated the theorem.  The figures are diagnostic only; they show that one
explicit moving genus character already removes a substantial part of the search space before
factorization.

## 8. Next algebraic frontier

The principal norm representation belongs to a binary quadratic-form class of discriminant
roughly `-4L`.  A full genus analysis should:

1. list all genus characters of the relevant order or ray class setting;
2. evaluate them on the target affine residue `-A mod L`;
3. determine which are forced to be trivial on every prime-ideal orientation dividing
   `A+B sqrt(-L)`;
4. combine independent character certificates before factoring `K`.

This may produce a much stronger factorization-free no-go sieve.  It may also identify the
rare prefixes for which all genus obstructions vanish and a genuine class-group orientation
problem remains.
