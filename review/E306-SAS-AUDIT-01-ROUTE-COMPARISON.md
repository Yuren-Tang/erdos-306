## 1. Common endpoint and common analytic backbone

The sparse and dense one-anchor routes prove the same squarefree-denominator characterization. Both retain:

```text
complete prime-pair denominator family on P,
finite Fourier selection modulo squarefree L,
direct actual-family major arc,
full-variance Gaussian tail,
adaptive complete-pair damping,
weighted retained-skeleton compression,
no-wrap, avoidance, and numerator induction.
```

The sparse route does not strengthen the headline theorem. Its claimed advantage is internal proof architecture.

## 2. Exact architectural change

The dense one-anchor route uses the whole top block `B` simultaneously as:

```text
cold-rigidity witness,
row sensor set,
fingerprint domain,
target-denominator sensor set.
```

Its top control has the form

```text
exact-cold theorem
 -> fingerprint rigidity
 -> fingerprint entropy / energetic level-set estimate
 -> weighted top partition.
```

The sparse route splits these functions:

```text
S = polylogarithmic actual-prime sensor interface,
R=B\S = positive-density retained cold witness.
```

Its top control has the form

```text
full-range population floor
 -> one common sampled core S
 -> shift-uniform row tails
 -> decoder-defect expansion
 -> robust exact-cold rigidity on G=R\U
 -> core-defect amplification
 -> direct energetic suppression after raw core enumeration.
```

The full-top target-denominator family is also replaced by

```text
E_b^S={rs:r|b,s in S}.
```

## 3. Fingerprint entropy verdict

Fingerprint entropy is genuinely no longer load-bearing.

### 3.1 Core enumeration

The sparse route counts all core assignments by

```text
Y_S=product_(s in S)s<=exp(O((log Z)^4)).
```

This is not an energy-level count. It has no fingerprint map, no injectivity theorem, no dependence on a level `R`, and no need to distinguish energetic patterns. Its entire logarithmic cost is dominated directly by `F_syncasymp Z/log^3Z`.

### 3.2 Robust cold rigidity

The robust theorem on `G` is a low-energy structural theorem:

```text
Q_G<c_w Z/log^3Z -> one exact integer label.
```

It does not estimate the number of high-energy assignments. It therefore does not reproduce fingerprint entropy, although it retains a substantial dense combinatorial proof.

### 3.3 Defect bookkeeping

The defect expansion does enumerate subsets `U`, but the enumeration is paid for explicitly by actual row-tail weights:

```text
small U: (1+delta)^N;
large U: 2^Ndelta^(N/2).
```

This is a weighted cluster expansion, not an energy-level coding theorem. No hidden independence is used.

## 4. Does the sparse route reconstruct equivalent complexity elsewhere?

Not in the precise fingerprint sense, but it does move substantial work into three places.

First, one must prove a simultaneous common-core theorem over all prime rows and residues. This requires the two-range population floor, quantitative concentration, and a global union bound.

Second, the exact-cold theorem must be robust for every positive-density retained subset `G`, rather than just the original full top block.

Third, the proof must separately control:

```text
energetic small defects,
large defects,
cold nonempty defects,
core mismatches through actual star phases.
```

These modules are not equivalent to fingerprint entropy, but they prevent the route from being a trivial or automatic simplification.

## 5. Sparse target-denominator observability

The sparse `b`-family is a genuine reduction in auxiliary load.

Dense one-anchor uses every top prime, giving reciprocal and square loads of orders

```text
O_b(1/log Z),
O_b(1/(Zlog Z)).
```

Sparse-anchor uses only `|S|asymp(log Z)^3`, giving

```text
O_b((log Z)^3/Z),
O_b((log Z)^3/Z^2).
```

The row distance remains `>>_b(log Z)^3`, sufficient for superpolynomial sibling suppression and decoder identification. No finite sibling reservoir or second auxiliary prime set is introduced. This is a real simplification rather than a renaming.

## 6. Exact meaning of “sparse”

The description

```text
sparse sensor interface with dense natural cold witness
```

is exact and should be preserved.

The route is sparse in:

```text
row sensors,
target-denominator observability,
core assignment interface.
```

It is not sparse in the cold witness. The complete internal graph on `G` remains essential in reciprocal dispersion, nondominant forcing, the label bound, and zero-exception elimination. The route therefore must not be described as a sparse-graph synchronization theorem.

## 7. Theorem hierarchy

The hierarchy is strictly cleaner than dense one-anchor:

```text
dense:
  cold rigidity -> fingerprint rigidity -> fingerprint entropy -> top partition;

sparse:
  cold rigidity + core amplification -> exact diagonal,
  otherwise direct exponential suppression.
```

The sparse proof also integrates target-denominator observability into the same actual-prime core and removes the full-top `b` family.

This is a strict reduction in theorem types. It is not merely an equivalent repackaging.

## 8. Standalone ordinary-proof burden

The current sparse human-proof file is shorter than the dense one-anchor human-proof file in raw written length. Raw length alone is not decisive, because the packets differ in exposition density.

At mathematical-module level, the sparse route removes:

```text
fingerprint rigidity,
fingerprint entropy,
energetic fingerprint level-set counting,
full-top target-denominator rows.
```

It adds or strengthens:

```text
full-range two-case population floor,
one common sampled core,
robust exact-cold theorem for arbitrary positive-density G,
decoder-defect expansion,
actual-phase core-defect amplification,
explicit cold nonempty-defect sector.
```

The resulting burden is best classified as **comparable**. The theorem hierarchy is cleaner and likely easier to organize, but the standalone proof still contains a long dense cold-rigidity argument plus new sampling and defect machinery. The audit therefore does not support the stronger claim that sparse-anchor should be preferred solely because it is shorter.
